# Architecture Decision Records

ADR ghi các quyết định kỹ thuật có ảnh hưởng dài hạn. Trạng thái dùng một trong:
`Proposed`, `Accepted`, `Superseded` hoặc `Deprecated`.

Các ADR từ `ADR-005` đến `ADR-010` thuộc baseline mã nguồn Mốc 0; `ADR-011` ghi
quyết định vòng đời dữ liệu Mốc 1 và `ADR-012` ghi quyết định phép đo Mốc 2. ADR-001
`ADR-013` ghi cấu hình nguồn nền và truy vết địa giới; `ADR-014` ghi adapter định
tuyến backend và phiên bản route bất biến; `ADR-015` ghi GPS, bằng chứng ảnh và
đồng bộ ngoại tuyến. ADR-001 đến ADR-004 được ghi trong
`docs/PROJECT_CONTEXT.md` trước khi thư mục này được tạo.
